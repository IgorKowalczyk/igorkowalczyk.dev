### Operating System

My dotfiles are available on [Github](https://github.com/igorkowalczyk/dotfiles), feel free to use them.

- **[Fedora 45](https://fedoraproject.org/)** - Workstation edition
- **[Hyprland](https://hyprland.org/)** - Tiling window manager
    - **[Hyprpaper](https://wiki.hyprland.org/Hypr-Ecosystem/hyprpaper/)** - Wallpaper manager
    - **[Hyprlock](https://wiki.hyprland.org/Hypr-Ecosystem/hyprlock/)** - Screen locker
    - **[Hypridle](https://wiki.hyprland.org/Hypr-Ecosystem/hypridle/)** - Idle manager
    - **[Hyprcursor](https://wiki.hyprland.org/Hypr-Ecosystem/hyprcursor/)** - Hypr cursor with [rose-pine](https://github.com/rose-pine/cursor) theme
- **[Waybar](https://github.com/Alexays/Waybar)** - Status bar and system tray
- **[Wofi](https://hg.sr.ht/~scoopta/wofi)** - Application launcher and system menu

### Coding

- **[Visual Studio Code](https://code.visualstudio.com/)** - Primary code editor
- **[Github](https://github.com)** - Code hosting and version control platform
- **[Dainty One Dark Pro](https://marketplace.visualstudio.com/items?itemName=alexanderte.dainty-one-dark-pro-vscode)** - Chroma 2, lightness 2
- **[Geist Mono](https://vercel.com/font)** - 14px font size

### Terminal

- **[KDE Konsole](https://konsole.kde.org/)**- Default terminal emulator
- **[Oh My Zsh](https://ohmyz.sh/)** - Zsh framework with plugins and themes
- **[ZSH Autocomplete](https://github.com/marlonrichert/zsh-autocomplete)** - Real-time type-ahead completion
- **[ZSH Gentoo](https://github.com/ohmyzsh/ohmyzsh/blob/master/themes/gentoo.zsh-theme)** - ZSH theme
